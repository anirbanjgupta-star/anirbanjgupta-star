# Anirban Gupta

If I need a new app, I build it, I don't download it..

I am not a professional programmer: I direct the build, judge the result, and question what does not survive real use..

Below is a selection of what I have built

## Selected builds

| Project | What it does | Built with |
|---|---|---|
| **Explainer Engine** | Turns a "how does it work?" question into a narrated 3D film, with every claim fact-checked before a frame is rendered.. Five films so far, the latest on the Mona Lisa.. | Remotion, Three.js, TypeScript |
| **Strategy Guru** | A private AI advisory firm: six advisors with their own agendas and rivalries, a board, and a CEO who can hire and fire them.. | Next.js, TypeScript, Claude |
| **Liminal** | A 3D scroll journey through time, the soul and identity, where you ask a question and the answer arrives as an experience.. | React, Three.js |
| **Outfit Advisor** | My wardrobe, photographed and catalogued, suits and watches matched by colour harmony, with a dashboard of what I actually wear.. | Node.js, JavaScript |
| **SeeFuture** | Puts a trend or weak signal in front of eleven expert councillors, each with a different lens, to spot an opportunity before it goes mainstream.. | Node.js, Claude |
| **Panopticon** | A digital twin of a team: watch its dynamics unfold in real time, then drop in an event and see how the team responds.. | Node.js, React |
| **Canyon** | A scrollable mobile app that explains ordinary things in depth (zippers, table fans, tea versus chai), so curiosity always has something to chew on.. | React, Vite, Vercel |
| **French Tide** | I record a voice note about tomorrow in my basic French; it returns a short French programme pitched just above my level, as audio for the metro.. | Node.js, Whisper |
| **Speech Judge** | An AI judge for Toastmasters speech contests, built on the real rules, with feedback a speaker can use.. | Node.js, React |
| **Dojo** | Learn a book, prove it, then live it: spaced repetition, teach-backs, and applying the book's framework to a real situation.. | Node.js, SQLite, React |
| **Control Tower** | A read-only dashboard of what my AI agents did: live states, a session tree, cost, and the guardrails each agent broke.. | React, Node.js |



If you are building something similar, or curious how one of these was made, I am always happy to compare notes :)
